# RECapp v0.3.0 — Prototype Snapshot

This repository preserves an earlier standalone HTML snapshot of **RECapp™ (Residential Ecosystem Capture of Application Processing and Procedures)**, a mortgage-pipeline workflow prototype.

The active project is maintained in **Kelly-RECapp**. This repository is retained as a version snapshot from the prototype's iterative development history.

The project explores visual pipeline management, mortgage workflow stages, milestone tracking, file notes, reminders, and operational exception visibility.

**Status:** historical prototype snapshot; not intended for production use or storage of real borrower information.
